# 书影 BookShadow

家庭藏书管理桌面应用，基于 Tauri 2 + Rust + React 构建。

## 功能

- **书籍管理**：新增、编辑、删除书籍，支持封面、简介、评分、地域、类别、语言、丛书、阅读日期等字段；支持从本地文件上传封面图片；地域、类别字段使用可搜索下拉，输入汉字即时过滤
- **内联编辑**：在书籍详情页直接切换编辑模式，无需另开弹层；封面保持可见便于对照
- **阅读状态**：四个状态「想读」「在读」「已读」「待购」；书卡封面显示彩色圆点，筛选面板显示各状态数量；购入待购书后可在书卡悬浮操作中点击「✓ 已购入」一键将状态转为「想读」；可记录开始/完成阅读日期
- **ISBN 自动填充**：输入 ISBN 或豆瓣链接（`book.douban.com/subject/…`），从豆瓣、Goodreads、Google Books、Open Library 自动拉取书籍元数据，封面自动下载缓存；可手动指定数据源，或选「自动」按优先级级联尝试；豆瓣 Cookie 失效时给出明确提示；设置页可一键打开豆瓣登录窗口，登录后 Cookie 自动提取保存（macOS）
- **批量导入**：打开导入面板后可拖拽图片或点击选择，自动识别条形码（EAN-13），批量从豆瓣等平台抓取元数据并导入；header 提供来源选择器（豆瓣 / Goodreads / Google Books / Open Library / 自动），适合中英文混合批次
- **标签**：为书籍添加自定义标签，支持输入时智能补全已有标签，按标签筛选
- **排序**：工具栏下拉切换排序方式（加入时间、书名、出版年份、评分）
- **筛选**：按阅读状态、星级、地域、类别、语言、年代、标签多维筛选；筛选数字联动更新，避免点击后无结果；地域/类别分主要/其他两级；年代显示各区间数量
- **全文搜索**：书名、作者、译者、出版社、丛书、简介、标签全文搜索（LIKE，支持中文），与侧边栏筛选可同时生效（AND 组合）
- **读书分析**：工具栏统计看板入口，展示 KPI（总/已读/在读/想读/待购）、年度阅读趋势图（真实时间轴，SVG 柱状图）、类别分布、地域分布、作者榜（前 20 作者）
- **AI 推荐**：想读视图下点击「AI 推荐」按钮，根据高分藏书的类别、地域、标签偏好对「想读」书单排序，每本书显示匹配评分（0.1 精度）和推荐理由；推荐排序在切换视图后保持有效，切回「想读」仍可使用；支持 Anthropic Claude 及兼容 OpenAI 格式的第三方端点（DeepSeek、Ollama 等）
- **AI 发现**：工具栏点击「AI 发现」按钮，同时抓取豆瓣新书速递（约 100 本）和 Goodreads new-releases（约 60 本），两路分别由 LLM 从真实候选书目中按偏好各筛选 5 本；结果分区展示「中文新书·豆瓣」和「英文新书·Goodreads」；无 Cookie 时降级到纯 LLM 生成；可一键「加入待购」（按需拉取元数据），批量处理时全程显示进度日志
- **AI 元数据补全**：编辑书籍时点击「AI 建议类别/地域/标签」，AI 分析书名/作者/简介后展示建议面板，类别/地域可逐项采用，标签可逐个点击添加，建议值在前端校验确保在字典范围内
- **书评**：每本书可写多篇 Markdown 书评，支持编辑/预览切换，支持从 `.md` 文件导入
- **网格 / 列表**：两种书籍浏览视图，滚动到底部自动加载更多，窗口大小和位置自动记忆
- **键盘快捷键**：`/` 聚焦搜索框（已有内容则全选），`e` 进入编辑模式，`←` / `→` 在书籍间导航，`ESC` 退出弹窗/详情；无焦点时 `ESC` 退出统计看板或清空所有筛选与搜索词回到全部；点击「书影」logo 同样清空全部筛选
- **数据导出**：从设置页导出全部书籍数据（JSON / CSV）

## 技术栈

| 层次 | 技术 |
|------|------|
| 前端 | React 19 + TypeScript + Vite |
| 样式 | Tailwind CSS v4 |
| 状态 | Zustand |
| Markdown 编辑器 | CodeMirror 6 |
| 桌面壳 | Tauri 2 |
| 后端 | Rust |
| 数据库 | SQLite（rusqlite bundled） |
| 搜索 | SQLite LIKE 全文搜索 |
| 条码识别 | rxing（EAN-13，纯 Rust） |

## 数据存储

所有数据存储在用户目录：

```
~/.bookshadow/
├── sqlite/bookshadow.db   # 书籍与书评数据库
├── covers/                # 封面图片本地缓存
└── config.json            # 应用配置
```

`config.json` 支持的字段：

| 字段 | 说明 |
|------|------|
| `google_books_api_key` | Google Books API Key，留空使用匿名访问（每日有配额限制） |
| `douban_cookie` | 豆瓣登录 Cookie，用于绕过反爬限制。macOS 可在设置页点击「打开豆瓣登录窗口（自动提取）」一键获取；也可从浏览器开发者工具 Network → Cookie 手动复制粘贴 |
| `anthropic_api_key` | Anthropic API Key（`sk-ant-...`），用于 AI 推荐与元数据补全 |
| `llm_base_url` | 自定义 API 地址，留空使用官方 Anthropic 端点；填入 DeepSeek / Ollama 等兼容 OpenAI 格式的地址可切换服务商 |
| `llm_model` | 模型名称，留空默认使用 `claude-sonnet-4-6` |

## 开发

```bash
# 安装依赖
npm install

# 启动开发（热重载，含 Rust 编译）
npm run tauri dev

# 仅启动前端预览
npm run dev

# 类型检查
npx tsc --noEmit

# 构建发布包（Universal Binary，同时支持 Apple Silicon 和 Intel）
npm run tauri:build
```

> Rust 由 Tauri 构建系统编译，无需单独运行 `cargo`。`tauri:build` 固定传入 `--target universal-apple-darwin`，产物为通用二进制，可在所有 Mac 上原生运行。

## ISBN 数据源优先级

1. **豆瓣读书** — 中文书元数据质量最佳（需配置 Cookie 以避免被拦截）；也支持直接粘贴豆瓣书籍链接精确抓取特定版本
2. **Goodreads** — 英文书首选；从书籍页 JSON-LD 结构化数据解析，自动提取系列信息
3. **Google Books** — 通用回退（支持配置 API Key）
4. **Open Library** — 最终回退

支持手动选择数据源，也可选「自动」按优先级级联尝试。批量导入面板 header 提供统一来源选择，适合整批英文书或整批中文书时一次切换。
